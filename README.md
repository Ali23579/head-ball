# Head Ball - Unity

Unity oyun motoru ve C# kullanılarak geliştirilmiş, popüler mobil oyunlardan ilham alan basit bir kafa topu oyunu.

## 🕹️ Açıklama

Bu proje, iki oyuncunun (veya bir oyuncu ve yapay zekanın) sadece kafalarını kullanarak birbirlerine karşı gol atmaya çalıştığı eğlenceli bir fizik tabanlı oyun konseptini Unity'de uygulamaktadır.

## ✨ Özellikler

* Temel 1v1 oyun mekaniği
* Karakter hareketi (zıplama, ileri/geri)
* Top fiziği ve etkileşimi
* Gol mekanizması ve skor takibi
* (Varsa ek özelliklerini buraya listele, örn: Basit yapay zeka, güçlendirmeler, farklı karakterler vb.)

## 💻 Kullanılan Teknolojiler

* Oyun Motoru: Unity (Kullandığın sürümü belirtebilirsin, örn: 202X.X.X)
* Programlama Dili: C#

## 🚀 Kurulum

1.  Bu repoyu bilgisayarınıza klonlayın veya ZIP olarak indirin.
    ```bash
    git clone [https://github.com/Ali23579/head-ball.git](https://github.com/Ali23579/head-ball.git)
    ```
2.  Unity Hub'ı açın.
3.  "Add" veya "Open" seçeneği ile indirmiş olduğunuz proje klasörünü Unity'ye ekleyin.
4.  Projenin Unity editöründe açılmasını bekleyin.

## ▶️ Kullanım

1.  Unity Editöründe `Assets/Scenes` (veya ana sahnenin bulunduğu klasör) içerisindeki ana oyun sahnesini (`.unity` uzantılı dosya) açın.
2.  Editörün üst kısmındaki "Play" (▶️) düğmesine tıklayarak oyunu başlatın.
3.  (Varsa oyun kontrollerini buraya ekle, örn: A/D = Hareket, W = Zıplama veya Ok Tuşları)
